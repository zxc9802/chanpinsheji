# 一键设计与区域编辑验收

## 功能

默认入口 `/studio`，保留 `/workflow/1` 到 `/workflow/6`。
仅上传产品文档即可原创设计瓶型、瓶盖及视觉，并生成文案、Logo、产品和外包装，共用原项目资产。
参考图收在可选区域，可用于风格借鉴或保留现有瓶型；新上传图默认仅参考风格，旧项目参考图继续保持结构。
同步整套设计使用当前已采用产品的结构，无需原始上传图。
编辑支持 OCR/物体多边形、SAM 精细分割、手动框选和顶点调整；指定文字、提示词或空提示词生成；预览后采用；历史恢复。
图片任务保留 jobId；重新查询不提交新生图请求。服务重启或完成任务过期后需明确重试。

## 边界

本次浏览器流程的文本提取和 OCR 自动识别使用测试替身，真实 OCR 路径另有协议与计费回归测试；尚未完成生产环境全链路验收。
无图原创路径的提示词和素材传递已回归验证；真实模型的原创瓶型效果尚未另外验收。
真实外部接口测试只使用合成图，没有发送真实产品文档。
区域识别可能需要用户修正；文字替换是图像编辑，需核对生成文字，配套文案可在原文案页面编辑。
项目及版本存在本浏览器 IndexedDB。任务队列沿用内存实现，不保证服务重启后续跑。
本地截图、真实模型结果与像素校验数据保存在忽略目录 `work/studio-qa/`，不随代码发布。

## 2026-09-18：三个独立设计方案

- 一键生成按三个不同的视觉方向分别执行规划、文案、Logo、内包装、外包装及原有审稿流程。每套内外包装使用本套的 Logo 与文案，保留白底、high 画质和任务 ID 续查。
- 成果总览并排展示三个方案。包装预览显示三视图画布的左侧正面列，点击后才挂载完整三视图及区域编辑器；Logo 总览展示三个完整标志。生成和整体改图提示词约定正、侧、背分别置于三个等宽列，不跨列。
- 切换方案同步当前采用的配套成果；选区、修改任务、审稿、版本历史按方案保存。同步当前方案不会重新生成另外两套。
- 已有单方案项目保留原方案，可补齐另外两个；中途失败后继续已有任务，不重复生成已完成方案。

验证：`npm run build` 通过，`node --test tests/*.test.mjs` 93 项通过。新增回归覆盖三套生成及参考图配对、第二套失败续跑、方案/版本/选区隔离、旧项目补齐、单套同步、重生保留历史、离开项目停止后续生成。

浏览器验证使用真实页面组件与本地合成 AI 响应：上传文档后生成三套；检查并排正面预览、点击第二套显示三视图、三个 Logo；采用第二套修改后切换第一套确认原图和历史未混入；刷新再打开第二套，修改和两条历史仍保留。本轮未以这组测试图片评估真实模型的设计质量，也未进行线上付费出图验收。

## 2026-09-18：按已有信息设计

- 文档和图片仅提取提供的信息，取消自动补全产品事实。品牌、产品、消费者数据块可缺省；额外材质、规格等信息保留为可编辑的补充资料，并随项目保存、传入规划与生成。
- 一键生成及资料编辑页取消品牌名、产品名等必填条件。无名称时设计纯图形标志，不把占位名称或空文案印到包装上。
- 视觉方案各分类、配色及用途可省略；嵌套描述和额外建议保留，取消每项 2400 字符和固定配色数量的拦截。空响应、损坏 JSON、上游停止等实际失败仍按原任务机制报告。
- 一键模式仅为当前方案规划文案，允许部分或零条文案，不再要求六项内容齐全或覆盖全部洞察。仅展示有内容的方案说明和文案。
- 三方案的系统对比资料单独传入，不占用用户设计想法的长度预算。技术请求大小限制仍保留。

验证：构建通过；98 项测试通过。新增回归覆盖只有材质/规格/品类、无品牌产品名、补充信息保存与再次导入、部分方案、空文案、三套完整生成和错误响应边界。

浏览器合成验收：上传仅有材质描述的 TXT，保持品牌/产品名为空，一键生成三个方案；查看方案仅展示内包装与其他建议；刷新后返回第一步仍保留补充资料；进入资料编辑页，无需补齐其他字段即可进入下一步。AI 响应为测试替身，本轮未进行真实付费出图或线上部署验收。`tsc` 仍存在此前的 8 项基线错误，本轮未新增。
