# 一键设计与区域编辑验收

## 功能

默认入口 `/studio`，保留 `/workflow/1` 到 `/workflow/6`。
上传瓶身参考和产品文档后生成文案、Logo、产品、外包装，共用原项目资产。
编辑支持 OCR/物体多边形、SAM 精细分割、手动框选和顶点调整；指定文字、提示词或空提示词生成；预览后采用；历史恢复。
图片任务保留 jobId；重新查询不提交新生图请求。服务重启或完成任务过期后需明确重试。

## 边界

本次浏览器流程的文本提取和 OCR 自动识别使用测试替身，真实 OCR 路径另有协议与计费回归测试；尚未完成生产环境全链路验收。
真实外部接口测试只使用合成图，没有发送真实产品文档。
区域识别可能需要用户修正；文字替换是图像编辑，需核对生成文字，配套文案可在原文案页面编辑。
项目及版本存在本浏览器 IndexedDB。任务队列沿用内存实现，不保证服务重启后续跑。
本地截图、真实模型结果与像素校验数据保存在忽略目录 `work/studio-qa/`，不随代码发布。
